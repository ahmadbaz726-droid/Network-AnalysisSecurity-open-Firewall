# Network-AnalysisSecurity-open-Firewall
## Project Overview
This was a university group project at TU Dublin where we tested and compared two open-source firewalls, IPFire and IPCop. My part of the project focused on IPFire.
The aim was to understand how firewall rules control network traffic and help protect a network from possible attacks.
## Tools and Technologies
- IPFire Firewall
- Kali Linux
- Xubuntu
- Virtual Machines
- Ping and Curl
- Network and firewall logs
## What We Did
As a group, we tested firewall configurations and checked how different network rules affected traffic.
For my IPFire section, I tested network connectivity, ICMP blocking, HTTP/HTTPS traffic and DNS filtering. I also used Kali Linux to simulate attack traffic and checked the firewall logs to see how IPFire responded.
## My Contribution
My main responsibility was working on the IPFire firewall.
I tested connectivity between network zones, checked firewall rules and carried out traffic blocking tests. I also worked on simulated attack testing and reviewed firewall logs to understand the results.
## Project Outcome
This project helped me understand how firewalls protect networks, how different rules affect traffic and why monitoring firewall logs is important.
I also gained more practical experience with IPFire, Kali Linux and network security testing.
